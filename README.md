# FreeLink AutoPilot — Android MVP

Исходный прототип автоматизации видимого интерфейса официального приложения ChatGPT.

## Статус
Это исходный MVP, а не проверенный релиз. APK будет собран GitHub Actions после добавления проекта. Перед реальным использованием нужно проверить Accessibility-метки на конкретной версии ChatGPT.

## Возможности прототипа
- Отдельное Android-приложение.
- Включение и выключение автоматизации.
- Работа только когда официальное приложение ChatGPT (`com.openai.chatgpt`) находится на экране.
- После обнаруженного завершения генерации пытается ввести точку и нажать отправку.
- Не использует OpenAI API.

## Ограничения
- Сначала пользователь вручную запускает ответ в нужном чате; после его завершения прототип пытается отправить точку.
- Автоматизация зависит от доступности подписей элементов в Accessibility-дереве ChatGPT и может перестать работать после обновления приложения.
- Нет гарантированной работы в фоне или при выключенном экране.
- В этой версии пока не реализованы постоянный лимит 100 циклов, надёжное восстановление после перезапуска, watchdog и режим удержания экрана.
- Служба специальных возможностей получает широкие полномочия. Включайте её только если доверяете приложению.

## Сборка APK
GitHub Actions запускает сборку при push в `main`. Готовый debug APK будет опубликован как артефакт workflow **Android APK**. Для установки скачайте артефакт, распакуйте ZIP и установите `app-debug.apk`. Debug APK предназначен для тестирования.

## Установка
1. Установите APK.
2. Откройте FreeLink AutoPilot.
3. Нажмите «Открыть специальные возможности» и включите службу FreeLink AutoPilot.
4. Откройте нужный чат ChatGPT.
5. Вернитесь в AutoPilot и нажмите «Запустить автоматизацию».
6. Вызовите первый ответ вручную. После распознанного завершения приложение попробует отправить точку.
7. Для остановки нажмите «Остановить автоматизацию» или отключите службу в настройках Android.

## План доработки
Диагностика Accessibility-дерева, ручной тест отправки, защита от дублей, настройка лимита циклов и режима удержания экрана, затем тестирование на Android 14.
